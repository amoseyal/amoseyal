## Data Analytics

### [U.S. Airline Performance Analysis](https://github.com/amoseyal/us-airline-performance-analysis)

An end-to-end analysis of **7,001,619 U.S. scheduled flights** examining airline and airport performance, seasonal delay patterns, cancellations, reported delay causes, and frequently operated routes using 2025 Bureau of Transportation Statistics data.

Built a reproducible analytical workflow using **R, SQL, DuckDB, Parquet, ggplot2, and Quarto**, processing 12 monthly source files into a validated annual dataset and publishing analysis-ready summary tables, visualizations, and a complete analytical report.

**Focus:** R · SQL · DuckDB · Data Analysis · Data Visualization · Aviation
