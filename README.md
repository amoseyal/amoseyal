## Featured Projects

### ✈️ U.S. Airline Performance Analysis
Analysis of more than 7 million U.S. scheduled flights using R, SQL,
DuckDB, Parquet, ggplot2, and Quarto.

Examines airline and airport performance, seasonal delay patterns,
cancellations, reported delay causes, and frequently operated routes
using 2025 Bureau of Transportation Statistics data.
