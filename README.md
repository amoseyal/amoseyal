## Cybersecurity Portfolio

### Governance, Risk & Compliance

#### [Control Assurance Engine](https://github.com/amoseyal/control-assurance-engine)

A Python-based cybersecurity GRC tool that evaluates structured security evidence against defined controls, distinguishes control exceptions from evidence-quality issues, maps findings to NIST CSF 2.0, applies risk scoring, and generates management-ready reporting.

The project implements seven controls across identity and access management, endpoint security, and third-party risk, with automated evidence validation, executive-level HTML reporting and visual analysis, and an 83-test automated test suite.

**Focus:** Python · pandas · pytest · GRC · Control Assurance · NIST CSF 2.0 · Risk Assessment

### Security Analytics & Detection Engineering

#### [Authentication Anomaly Analyzer](https://github.com/amoseyal/auth-anomaly-analyzer)

A Python-based security analytics tool that analyzes authentication logs to detect brute-force activity, password spraying, and suspicious successful logins through time-window analysis and event correlation.

The project produces structured security alerts for investigation and reporting and includes authentication-log validation, a command-line interface, CSV export, and a 14-test automated unit and integration test suite.

**Focus:** Python · pandas · Detection Engineering · Authentication Security · Log Analysis · pytest

## Data Analytics

### [U.S. Airline Performance Analysis](https://github.com/amoseyal/us-airline-performance-analysis)

An end-to-end analysis of **7,001,619 U.S. scheduled flights** examining airline and airport performance, seasonal delay patterns, cancellations, reported delay causes, and frequently operated routes using 2025 Bureau of Transportation Statistics data.

Built a reproducible analytical workflow using **R, SQL, DuckDB, Parquet, ggplot2, and Quarto**, processing 12 monthly source files into a validated annual dataset and publishing analysis-ready summary tables, visualizations, and a complete analytical report.

**Focus:** R · SQL · DuckDB · Data Analysis · Data Visualization · Aviation
